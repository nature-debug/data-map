# 이곳만은 꼭 지키자 — 선정지, 그 후의 기록

한국내셔널트러스트 시민공모전 '이곳만은 꼭 지키자' 선정지(2000년 제1회~)의 현재 보전상태를 지도에서 살펴보는 웹사이트입니다.

- 왼쪽: 네이버 지도 — 시/도 경계를 클릭하면 해당 지역으로 이동, 대상지는 현재 보전상태 색깔 핀으로 표시
- 오른쪽: 대상지 목록 — 검색, 현재 상태 / 가치(세부 가치) / 선정 회차 필터, 자연유산·문화유산별 카드
- 카드를 누르면 상세 정보(주요 가치, 당시의 위협과 대응, 현재 상태, 변화의 기록, 관련 자료)를 볼 수 있습니다.

## 실행

```bash
npm install
cp .env.example .env   # 값 채우기 (아래 참고)
npm run dev            # http://localhost:3000
```

## 환경 변수 (`.env`)

| 이름 | 설명 |
| --- | --- |
| `NEXT_PUBLIC_NAVER_MAP_KEY_ID` | 네이버 클라우드 플랫폼 Maps(Dynamic Map) Client ID. 비어 있으면 기본 SVG 지도를 사용합니다. 콘솔의 **Web 서비스 URL**에 `http://localhost:3000`과 배포 도메인을 등록해야 합니다. |
| `SPREADSHEET_ID` | (선택) 데이터 구글 시트 ID. 기본값은 코드에 있는 시트입니다. |
| `SHEET_GID` | (선택) 시트 탭 gid. 기본값은 '총합 데이터(기존 수상지)' 탭입니다. |

`.env`는 git에 올라가지 않습니다. 배포 환경(Vercel 등)에는 같은 이름으로 따로 등록하세요.

## 데이터

- 구글 시트를 CSV로 읽어옵니다 (`src/lib/sheets.ts`). 시트는 **링크가 있는 모든 사용자 보기** 권한이어야 합니다.
- 시트를 수정하면 최대 5분 뒤 사이트에 반영됩니다.
- 사진(BO열)은 구글 드라이브 링크를 사용하며, 각 파일도 **링크가 있는 모든 사용자 보기** 권한이어야 표시됩니다.
- 열 위치(B, C, F, AG …)를 기준으로 읽기 때문에 시트에 열을 끼워 넣거나 순서를 바꾸면 `src/lib/sheets.ts`의 열 문자도 함께 수정해야 합니다.
